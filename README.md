# QUIZ APP

## Project Overview

The Quiz App is an interactive web-based application developed using HTML, CSS, and JavaScript. The main purpose of this project is to provide users with an engaging platform to answer multiple-choice questions and instantly evaluate their performance.

The application allows users to select a quiz from available categories or start a random quiz. Questions are displayed one at a time with multiple-choice options, and users receive immediate feedback after selecting an answer. The app calculates the total score automatically and displays the final result along with correct and incorrect answers at the end of the quiz.

The application is designed with a modern and responsive user interface that works smoothly across desktops, laptops, tablets, and mobile devices.

---

# Objectives

* To create an interactive quiz application.
* To present multiple-choice questions to users.
* To provide immediate feedback for submitted answers.
* To calculate and display quiz scores automatically.
* To display correct and incorrect answers after quiz completion.
* To design a responsive and visually attractive user interface.
* To improve user learning and engagement through quizzes.

# System Workflow

1. User opens the application.
2. Available quizzes are displayed.
3. User selects a quiz or random quiz.
4. Questions appear one at a time.
5. User selects an answer.
6. Immediate feedback is shown.
7. Score is updated automatically.
8. After completing all questions:

   * Final score is displayed
   * Answer review is shown

# Limitations

## 1. Static Question Data

Questions are stored locally inside the application.

---

## 2. No User Login System

The current version does not support user authentication.

---

## 3. No Online Score Storage

Scores are not saved permanently in an online database.

---

## 4. Limited Quiz Categories

Only predefined quizzes are available.

---

## 5. No Multiplayer Support

Users cannot compete with others in real time.
